## Operating Rules
1. Non-trivial work should have one detailed task note under `plans/YYYY-MM/`.
2. Issue-backed work uses `issue-<number>-<slug>.md`.
3. Work without a GitHub Issue uses `adhoc-YYYY-MM-DD-<slug>.md` and should explain why no Issue exists.
4. Completed task details stay in the monthly task note; this file should retain only summary links.
5. Older root-level planning history is rotated into `plans/archive/YYYY-MM.md`.
